🛠 Installation — one-time setup
1
Download and unzip the package
Anywhere on your Mac — e.g. in your Documents folder
Once
1
Click the link shared by your colleague, or go to the GitHub repository
2
Click Code → Download ZIP
3
Open the downloaded .zip — macOS will unzip it automatically
4
Move the TypeAct folder wherever you like (e.g. Documents)
💡
Keep the folder in the same place — if you move it after installation you may need to repeat step 2.
2
Fix file permissions in Terminal
Required after downloading a ZIP from GitHub — macOS removes executable permissions
Once
1
Open Terminal (search with Spotlight: ⌘Space → type "Terminal")
2
Copy and paste this command, then press Enter:
Terminal
~$ chmod +x ~/Downloads/TypeAct-main/INSTALLA.command ~/Downloads/TypeAct-main/avvia.command
~$
💡
If you moved the folder to Documents, replace ~/Downloads/TypeAct-main with the actual path to your folder.
3
Run INSTALLA.command
Installs the required dependency and prepares the files
Once
1
Open the TypeAct folder
2
Double-click INSTALLA.command
3
If macOS shows a security warning, see the troubleshooting section below
4
Wait for the script to finish — System Settings will open automatically
⚠️
The script will automatically open System Settings to the Accessibility panel. Continue with step 4 without closing it.
4
Grant Accessibility permission to Terminal
Required — without this TypeAct cannot simulate keyboard input
Required
1
In System Settings, find and click Accessibility in the left panel
2
Click the lock 🔒 at the bottom left and enter your Mac password
3
Click the + button to add a new app
4
Navigate to Applications → Utilities, select Terminal and click Open
5
Make sure the toggle next to Terminal is enabled (green)

🔧 Troubleshooting
"avvia.command" or "INSTALLA.command" Not Opened
macOS Gatekeeper blocks unsigned files downloaded from the internet. Do not click "Move to Bin" — use right-click → Open instead.

"could not be executed because you do not have appropriate access privileges"
The file is missing executable permission — this happens when unzipping from GitHub. Open Terminal and run:
Terminal
~$ chmod +x ~/Downloads/TypeAct-main/INSTALLA.command ~/Downloads/TypeAct-main/avvia.command
The script doesn't respond when I type the trigger
Check that Terminal has the Accessibility permission enabled (Step 4). If you added it but it still doesn't work, remove it and add it again, then restart avvia.command.
How do I add new snippets?
Open gestisci_snippet.html in Chrome, load your snippets.json, add the snippets you want and save with ⌘S. Restart avvia.command to load them.
Does it work with Slack, Teams, the browser?
Yes — it works in any app where you can type text: Slack, Microsoft Teams, Chrome, Safari, PowerPoint, Word, and more.
Does it work on iPad or Windows?
No — TypeAct is macOS only. It relies on macOS Accessibility APIs that don't exist on iPadOS or Windows.
