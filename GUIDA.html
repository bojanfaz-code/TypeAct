❓ Frequently asked questions
The script doesn't respond when I type the trigger
Check that Terminal has the Accessibility permission enabled (Step 3). If you added it but it still doesn't work, remove it and add it again, then restart the script.
macOS says "unidentified developer" when I open INSTALLA.command
This is normal for unsigned .command files. Go to System Settings → Privacy & Security, scroll down and click "Open Anyway" next to the file name.
Does it work on Windows?
No, TypeAct is designed for macOS only. The Accessibility API it relies on is specific to macOS.
How do I add new snippets?
Open gestisci_snippet.html in Chrome, load your snippets.json, add the snippets you want and save with ⌘S. Restart avvia.command to load the changes.
Does it work with Slack, Teams, the browser?
Yes — it works in any application where you can type text: Slack, Microsoft Teams, Chrome, Safari, PowerPoint, Word, and more.
